# 费曼学习法测试 Skill

基于用户已有笔记，用费曼学习法检测真实理解程度。纯对话互动，不写文件。

## 执行流程

### 第 0 步：定位笔记

按用户指定的主题搜索笔记，选择 **3-5 篇核心笔记**读取。

笔记选择优先级：
1. 用户明确指定的笔记
2. 「基础概念」目录下的笔记
3. MOC 中标记为核心/基础的链接
4. 最近修改过的笔记

排除：日记、收件箱碎片、纯操作日志类文件。

从选中笔记中提取「临时测试范围摘要」：核心概念 + 概念间关系 + 易错点，控制在 10 行以内。不要生成完整知识地图。

### 第 1 步：出题

每次只出一题。默认从初级开始，通过后提升难度。

| 级别 | 题目形式 |
|------|---------|
| 初级 | 「请用最简单的语言解释 X，假设对方完全不懂」 |
| 中级 | 「请举一个 X 的实际例子」「X 和 Y 有什么区别」 |
| 高级 | 「什么情况下不该用 X？」「X 的底层原理是什么？」 |

### 第 2 步：评判与追问

**出题后等用户回答，不提前展示笔记原文。** 用以下维度在心中评判（不逐条念给用户）：定义准确性、是否用自己的话、能否举例、能否区分相近概念、是否知道适用场景和限制。

**追问规则**：
- 每轮只追问一个点，最多 2-3 轮
- 追问方向：选用户回答暴露的最大弱点切入
  - 跳过关键点 → 「你提到 A，那 B 呢？它和 A 是什么关系？」
  - 表述模糊 → 「你说它『很重要』，能不能举个具体的例子？」
  - 用术语解释术语 → 「如果你不能用『X』这个词，会怎么解释？」
  - 回答正确 → 提升难度
- 答不上来时：先给提示 → 仍不行则给 3-5 句标准解释 + 指向具体笔记 + 标注为薄弱点

### 第 3 步：循环或结束

- 默认 3 题一组，做完询问是否继续
- 用户说「可以了」「停止」→ 立即停止
- 总结用三档：✅ 掌握扎实 / 🟡 基本理解但缺细节 / 🔴 需要重新复习，每档指向对应笔记

### 外部资料规则

- 默认不查外部资料，基于已有笔记测试
- 笔记明显不足或用户明确要求 → 询问用户是否启用搜索
- 不自动调用 deep-research

## 何时读取参考文件

- 需要费曼核心原则、追问技巧详解 → 读 `references/feynman-principles.md`
