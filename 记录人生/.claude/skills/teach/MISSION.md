# Mission: AI 工作流与 Skills 工程设计

## Why
用户在代码审查、开发和问题调查的日常工作中，希望通过设计更好的 AI skills 和工作流，让 AI 稳定可靠地协助完成工作。目前能用 skill-creator 写 skills，但总感觉有所不足——不清楚什么样的 skill 才算「好」，也不确定 Context Engineering、Harness Engineering、MCP 这些机制何时该用、怎么组合。

## Success looks like
- 能判断一个 skill 是否设计得好，并说出具体哪里好、哪里不好
- 能独立设计出 AI 执行稳定（不跑偏、输出一致）的 skill
- 能根据任务特征选择正确的机制：skill vs workflow vs MCP vs 纯 prompt
- 能提供精准的上下文（Context Engineering），让 AI 不用猜
- 能在实际工作中用自己设计的 skill 节省时间

## Constraints
- 工作中使用 Copilot + skill-creator，个人使用 Claude Code
- 学习时间零散，每次学习应短小精悍（15-30 分钟）
- 偏好实战驱动，概念服务于动手

## Out of scope
- AI 底层原理（transformer 架构、训练方法等）
- 前端/UI 相关的 AI 应用
- 模型部署与运维
