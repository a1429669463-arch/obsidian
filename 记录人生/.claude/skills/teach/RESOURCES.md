## Knowledge

- [Anthropic: Agent Skills 文档](https://docs.anthropic.com/en/docs/agents-and-tools/agent-skills)
  Anthropic 官方 skill 设计指南，涵盖 skill 结构、触发机制、最佳实践。Use for：skill 结构设计的权威参考。

- [OpenAI: Harness Engineering — Leveraging Codex in an Agent-First World](https://openai.com/index/harness-engineering/)
  用户已读过此文，6 条关键原则已记录在 Harness Engineering 笔记中。Use for：理解 skill 与更大系统（harness）的关系。

- [Anthropic: Context Engineering 最佳实践](https://docs.anthropic.com/en/docs/build-with-claude/context-windows)
  官方上下文管理指南。Use for：回答「给什么信息才算好」——将在第 2 课使用。

## Wisdom (Communities)

- [r/ClaudeCode](https://reddit.com/r/ClaudeCode)
  Claude Code 用户社区，含 skill/workflow 设计讨论。Use for：看其他人的 skill 设计思路和踩坑经验。

- [Claude Code 官方 Discord](https://discord.gg/anthropic)
  官方 Discord，有 skill 设计频道。Use for：skill 问题的实时反馈。

- [Anthropic: Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents)
  Anthropic 官方 Agent 设计指南，定义六种工作流模式（Prompt Chaining / Routing / Parallelization / Orchestrator-Workers / Evaluator-Optimizer / Autonomous Agent）和「简单优先」原则。Use for：工作流设计模式的权威参考、判断何时该用 Agent vs Workflow。

- [GitHub: slavakurilyak/building-effective-agents](https://github.com/slavakurilyak/building-effective-agents)
  Anthropic 六种模式的多种框架实现（pydanticAI, crewAI, instructor 等）。Use for：看同一模式在不同框架下的实现差异。
