当用户给出任务时，`Agent` 不只是回答问题，而是能够根据目标自主拆分任务流程，并决定需要调用哪些工具。

`Agent` 可以通过工具调用获取外部信息或执行操作。  
在一些平台中，外部工具可以通过 [[MCP]] 接入，从而被 `Agent` 调用。

在执行过程中，如果遇到错误、信息不足或结果不符合预期，`Agent` 可以根据中间结果调整计划，继续尝试不同方法，直到完成任务，或判断无法继续执行。

简单来说：

Agent = [[LLM]] + memory(记忆) + planning skills(规划)+tool use(工具)
