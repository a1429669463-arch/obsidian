`MCP` 即 Model Context Protocol，中文可以理解为「模型上下文协议」。

它是一种开放标准，用于让 AI 应用以统一方式连接外部系统，例如：

- 本地文件
- 数据库
- 搜索引擎
- API
- 业务系统
- 自动化工具

MCP 的作用不是让模型本身变聪明，而是为「AI 应用如何接入外部工具和数据源」提供统一协议。

如果没有这类统一协议，不同工具接入不同 AI 平台时，往往需要分别适配各个平台的接口。

例如：

```text
工具A → 接入 Claude：写一套适配代码
工具A → 接入 ChatGPT：再写一套适配代码
工具A → 接入 Cursor：再写一套适配代码
```

MCP 虽然提供了统一的工具接入协议，但在实际使用中，工具名称、说明、参数等元信息通常需要提前提供给 AI。  

因此，接入过多 MCP 工具时，这些元信息会占用 [[上下文]]，并不一定能做到真正的按需加载。
