一个被Ai按需使用的工具，类似于[[MCP]]，维护一个skill.md`

结构大致如下
```
skill.md
├─ 元信息 / 触发说明
│   └─ 帮助 AI 判断：什么时候应该使用这个 Skill
│
├─ 指令层
│   └─ 一旦决定使用 Skill，就把这部分加入上下文
│      告诉 AI：该怎么做、步骤是什么、注意事项是什么
│
└─ 资源层
    ├─ scripts/
    │   └─ 可执行脚本、工具代码
    ├─ references/
    │   └─ 参考文档、模板、示例、规范
    └─ examples/
        └─ 输入输出样例
```

元信息一般最先被索引或读取，用来判断是否调用 Skill。  

一旦调用 Skill，skill.md 中的主要指令会进入上下文。  
scripts、references 等资源不一定全部进入上下文，而是根据 skill.md 的指示按需读取或执行。
