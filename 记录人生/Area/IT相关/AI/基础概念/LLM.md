`LLM` 即 Large Language Model，中文通常称为「大语言模型」。

它可以理解为一种通过大量文本数据训练出来的深度学习模型，常见架构是 Transformer。  

LLM 的核心能力是根据上下文预测下一个 [[Token]]，并不断重复这个过程，最终生成完整回答。

因为 LLM 的生成本质上带有预测性质，所以它无法百分百保证输出一定正确，也可能产生 [[Ai幻觉]]。

LLM是[[Agent]]的思考核心，相当于人类的大脑

## 生成流程示意

例如用户提问：

```text
今天天气怎么样？
1. 根据问题和上下文，预测第一个 Token
2. 将生成出的 Token 加入上下文
3. 根据新的上下文继续预测下一个 Token
4. 重复这个过程，直到生成完整回答
```

LLM 本身不能直接感知外部环境。  
例如，它不能自己知道当前天气、数据库内容、文件系统状态或最新网页信息。

如果需要获取外部信息，就需要通过平台提供的 `Tool` 或外部系统来完成

外部工具可以通过 [[MCP]] 接入，从而被调用
