## FW公表日（`fw_opn_ymd`）

`fw_opn_ymd` 用于判断该レポート是否已经执行过初回配信。

### 初回配信

| 项目           | 内容                   |
| ------------ | -------------------- |
| `fw_opn_ymd` | 空 → 设置为当前处理日         |
| 審査レポート       | 新規作成（INSERT）         |
| 販社取得元        | `FL_MST_HAN_RPT_TBL` |

`fw_opn_ymd` 为空时，表示还没有生成过審査レポート，因此需要从販社マスタ取得对象，并新規コピー作成審査レポート。

---

### 再配信

| 项目           | 内容                   |
| ------------ | -------------------- |
| `fw_opn_ymd` | 已存在，不变更              |
| 審査レポート       | 状态更新のみ（UPDATE）       |
| 販社取得元        | `FL_HAN_RPT_KNR_TBL` |

`fw_opn_ymd` 已存在时，表示審査レポート已经生成过，因此不会再次新規作成，只更新既存记录的状态。

---

### 要点

```text
fw_opn_ymd 为空     → 初回配信 → INSERT
fw_opn_ymd 已存在   → 再配信   → UPDATE
```

`fw_opn_ymd` 不只是公表日，也起到“是否已初回配信”的判断标志作用。
