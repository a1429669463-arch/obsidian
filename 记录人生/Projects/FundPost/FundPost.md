## 画面投稿文件与 Batch 取り込み路径整理

### 1. 画面投稿文件的存放位置

画面上传/投稿进来的文件会被存放到以下路径：

```
/nas/val/
```

该路径挂载在 NSFS 的磁盘上。

### 2. Batch 取り込み路径的修正内容

本次修改的重点是：

Batch 取り込み使用的路径，需要挂载到画面侧所使用的路径上，最终也指向同一个存放位置。

也就是说，画面投稿进来的文件路径和 Batch 取り込み使用的路径，最终需要统一到同一个实际目录。

### 3. 修改原因

原本的结构中：

```
画面投稿进来的路径
Batch 取り込み使用的路径
```

两者并不相同。

由于路径不一致，可能导致画面上传的文件和 Batch 取り込み处理的文件不在同一个实际位置，因此需要进行这次修改。

### 4. FP-DR 画面的处理方式

FP-DR 画面不是直接使用同一个路径，而是通过符号链接来实现路径统一。

也就是说，FP-DR 画面侧看起来使用的是自己的路径，但实际通过符号链接指向同一个文件存放位置。

### 5. 结论

本次修改的核心是：

```
让画面投稿路径与 Batch 取り込み路径最终指向同一个实际存放位置。
```

其中普通画面通过路径挂载实现统一，FP-DR 画面则通过符号链接实现统一。
