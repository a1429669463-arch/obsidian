# Git 学习工作区

这是用户的 Git 实战学习工作区，通过多节课逐步掌握 Git 的中等难度场景。

## 工作区文件

- `MISSION.md` — 学习目标（为什么学、成功标准、边界）
- `NOTES.md` — 用户偏好和教学笔记
- `RESOURCES.md` — 高质量学习资源（知识源 + 社区）
- `lessons/*.html` — 课程文件，每课一个独立 HTML，编号递增
- `reference/*.html` — 参考文档（速查表、流程图、术语表）
- `learning-records/*.md` — 学习记录（已有知识、关键领悟、纠正的误解）

## 课程设计原则

- **实战驱动**：每课围绕用户真实遇到的场景展开，概念服务于动手
- **短小精悍**：每课 15-30 分钟，一个场景一个收获
- **最近发展区**：根据 learning-records 判断用户当前水平，教刚好有挑战的内容
- **中文授课**
- **每课必含**：知识讲解 → 互动练习（反馈闭环）→ 推荐阅读来源 → 提醒可以追问

## 用户当前水平

- 已掌握：git commit, git pull, git push
- 目标：能独立应对 20-30 个中等难度场景，不用 Google
- 使用场景：个人项目为主 + 偶尔团队协作
