# Mission: Git 实战能力

## Why
日常个人项目和偶尔团队协作中使用 Git 做版本管理。目前已掌握 commit/pull/push，但遇到稍复杂场景（如"本地改了文件不想被跟踪"、"查某文件在各分支的最新版本"）就不知道该用什么命令，每次都要 Google。希望告别这种"卡住就搜"的状态。

## Success looks like
- 独立应对 20-30 个常见中等难度 Git 场景，不用临时搜索
- 看到一个 Git 需求时，心里有数该用哪条命令（或哪几条组合）
- 理解核心概念（暂存区、分支指针、远程跟踪分支）足以推导命令
- 遇到没见过的场景时，能说出涉及哪个子系统然后精准搜索

## Constraints
- 每课 15-30 分钟，中文授课，实战驱动
- 使用场景以个人项目为主，偶尔团队协作
- 终端实操，不用 GUI 工具

## Out of scope
- Git 内部实现（对象数据库、packfile 格式等）
- Git 服务器搭建与管理
- CI/CD 流水线中的 Git 用法
- GUI 工具
