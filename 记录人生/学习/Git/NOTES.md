# Teaching Notes — Git

## 用户偏好
- 实战驱动，概念服务于动手
- 短课时（15-30 分钟）
- 中文授课，终端实操
- 个人项目为主，偶尔团队协作

## 用户提出的场景（优先覆盖）
1. 本地改了文件但不想被跟踪 → 第 1 课
2. 查询所有分支中某文件的最新版本在哪 → 第 2 课

## 自然延伸场景（按 ZPD 排序）
3. 改错了怎么撤销（工作区 / 暂存区 / 已提交）
4. 提交信息写错了 / 漏了文件怎么改
5. stash：临时保存工作切去别的事
6. 分支操作：创建、切换、合并、删除
7. git log 过滤技巧
8. git diff 各种比较方式
9. 远程仓库：fetch vs pull、remote 管理
10. rebase 入门
11. cherry-pick
12. 解决合并冲突
13. .gitignore 高级用法
14. git blame 和 bisect

## 观察
- 用户动机是"实战中卡住了"→ 直接从场景出发教学
- 每课围绕 1 个场景，顺带教相关概念
