# Git 学习资源

## Knowledge

- [Pro Git Book](https://git-scm.com/book/zh/v2)（中文版）
  Git 权威参考书，从基础到内部原理全覆盖。Use for：查任何 Git 概念的权威解释。

- [Learn Git Branching](https://learngitbranching.js.org/)
  浏览器里的交互式 Git 可视化练习，用游戏方式理解分支、合并、变基。Use for：理解 Git 的 DAG 模型，最直观的分支学习工具。

- [Atlassian Git Tutorials](https://www.atlassian.com/git/tutorials)
  图文并茂的中等难度教程，分支策略和工作流部分尤其出色。Use for：团队协作场景和工作流选择。

- [Oh Shit, Git!?!](https://ohshitgit.com/)
  用幽默短句覆盖常见 Git 灾难的恢复方法（丢提交、错分支、合并冲突）。Use for：出问题时快速找到恢复命令。

## Wisdom (Communities)

- [r/git](https://reddit.com/r/git)
  Git 专属讨论区，中高信号。Use for：疑难问题讨论、最佳实践。

- [Stack Overflow — git tag](https://stackoverflow.com/questions/tagged/git)
  Use for：具体场景的命令写法搜索。
