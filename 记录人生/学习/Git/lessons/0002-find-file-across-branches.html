第 2 课：查找文件在哪个分支有最新版本

分支搜索 git log 场景驱动 约 25 分钟

真实场景：你记得前几天在某个分支上改过 HOME.md，加了一段很重要的内容，但忘了是哪个分支。现在你在 main 分支上，怎么快速找到那个"藏了最新版本"的分支？

核心思路：分两步走

这个问题可以拆成两个独立的小问题：

  1. 找到该文件"最新"的提交是哪一个（在所有分支中找）
  2. 看这个提交在哪些分支上

每条命令各解决一步，然后拼起来就是答案。

第一步：找到文件的最新提交

你平时用的 git log 只看当前分支。加 --all 参数就能搜索所有分支：

# 查看所有分支中，某文件的所有提交记录（简洁版）
git log --all --oneline -- HOME.md

输出大致是这样：

b327d45 merge 6b42c4c 20260615 f683040 20260508 a1b2c3d 修复 HOME.md 中的链接 89ef012 初始导入

最上面那一行就是最新的提交。如果只想取这一个：

# 只取最新的一条
git log --all --oneline -1 -- HOME.md
语法说明：命令末尾的 -- 后面跟文件名，告诉 Git"后面的参数是文件路径，不是分支名"。当你的文件名和分支名可能冲突时，这个 -- 很重要。养成习惯总是好的。

提取提交哈希（给下一步用）

# 只输出哈希值，不输出其他信息
git log --all -1 --format=%H -- HOME.md

--format=%H 表示"我只要完整的 40 位 commit hash"。这是给脚本和命令组合用的格式。

你想要的用这个
完整日志，可读性好git log --all -- HOME.md
简洁列表，一行一条git log --all --oneline -- HOME.md
只要最新一条git log --all --oneline -1 -- HOME.md
只要哈希值（给脚本用）git log --all -1 --format=%H -- HOME.md

第二步：看这个提交在哪些分支上

# 给定一个 commit hash，看它被哪些分支包含
git branch --contains <commit-hash>

例如：

$ git branch --contains b327d45
  feature/update-home
* main
  fix/typo

* 标记的是你当前所在的分支。如果要包含远程分支：

git branch -a --contains <commit-hash>
# -a 表示 all，包括远程分支（remotes/origin/xxx）

合并：一行命令搞定

把上面两步串起来——用 $() 把第一步的结果喂给第二步：

# 查找拥有 HOME.md 最新版本的所有分支（含远程）
git branch -a --contains $(git log --all -1 --format=%H -- HOME.md)

这条命令做了什么：

1. git log --all -1 --format=%H -- HOME.md → 输出 b327d45e...（HOME.md 最新提交的哈希） 2. git branch -a --contains b327d45e... → 列出所有包含这个提交的分支 结果是：拥有该文件最新版本的分支列表
如果输出为空？说明这个提交不在任何命名分支上——可能是 detached HEAD 状态下的提交，或者该分支已经被删除了。可以用 git reflog 找回来，这个后面会讲。

进阶：不止要看"最新的"，还要看"每个分支上是什么样的"

上面的方法只回答了"哪个分支有最新版本"。有时候你还想知道每个分支各自的版本差异：

# 列出所有本地分支，并显示该文件在每个分支上的最近一次提交
git log --all --oneline --graph -- HOME.md

--graph 会用 ASCII 画出分支分叉的拓扑图，一眼能看出来文件在不同分支上的演化路径。

另一个有用命令——检查某个文件是否存在于某个分支上：

# 列出 feature/xxx 分支上的 HOME.md
git ls-tree -r feature/update-home -- HOME.md

# 如果输出为空 → 这个分支上没有这个文件
# 如果有输出 → 会显示文件的 blob 哈希和路径

场景总结：根据你的问题选命令

你想知道什么命令
这个文件在所有分支上的提交历史git log --all --oneline -- <file>
哪个分支有这文件的最新版本git branch --contains $(git log --all -1 --format=%H -- <file>)
某个特定分支上有没有这个文件git ls-tree -r <branch> -- <file>
所有分支上这文件的演化图git log --all --oneline --graph -- <file>
这文件在另一个分支上内容是什么git show <branch>:<file>

练习 3：真实操作

在你当前的 Obsidian vault 仓库里实操：

  1. 用 git log --all --oneline -- HOME.md 查看 HOME.md 在所有分支上的提交
  2. 如果是多分支仓库，用组合命令找出哪个分支有 HOME.md 的最新版本
  3. 找一个你确定存在的文件，用 git show <另一个分支名>:<文件路径> 看看它在别的分支上内容一样不一样

如果当前仓库只有一个 main 分支，可以先用 git checkout -b test-search 创建一个测试分支，改一下文件，切回 main，再搜。（别忘了之后可以 git branch -d test-search 删掉）

本节要点

  • git log --all 搜索所有分支，不只是当前分支
  • -- 分隔选项和文件路径，防止歧义
  • git branch --contains <hash> 反向查找——给定一个提交，找它属于哪些分支
  • $() 把命令的输出嵌入到另一条命令中，实现组合
  • 组合拳：git branch --contains $(git log --all -1 --format=%H -- <file>)
