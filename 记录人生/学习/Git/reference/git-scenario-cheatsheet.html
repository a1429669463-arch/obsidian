第 1 课 · 文件忽略与取消跟踪

echo "file" >> .gitignore
忽略从未跟踪过的文件（Untracked 文件专用）
git update-index --skip-worktree <file>
忽略已跟踪文件的本地修改（git status 不再显示）
git update-index --no-skip-worktree <file>
恢复：让 Git 重新关注这个文件的修改
git ls-files -v | grep '^S'
查看所有被 skip-worktree 标记的文件（S=skip, h=assume-unchanged）
git rm --cached <file>
永久停止跟踪文件（保留本地副本）。之后需加 .gitignore

决策：该用哪个？

git status 看到文件 → Untracked? → .gitignore
git status 看到文件 → modified? → skip-worktree（临时）或 rm --cached（永久）

第 2 课 · 跨分支查找文件

git log --all --oneline -- <file>
查看文件在所有分支上的提交历史（一行一条）
git log --all -1 --format=%H -- <file>
只取该文件最新提交的完整哈希值
git branch --contains <hash>
给定提交哈希，列出包含它的所有本地分支
git branch -a --contains $(git log --all -1 --format=%H -- <file>)
一行命令：找拥有该文件最新版本的所有分支（含远程）
git log --all --oneline --graph -- <file>
可视化文件在各分支上的演化路径（ASCII 拓扑图）
git show <branch>:<file>
直接查看文件在指定分支上的内容（不用切分支）
git ls-tree -r <branch> -- <file>
检查文件是否存在于指定分支上

组合命令模式

把 A 命令的输出喂给 B 命令 → 用 $(...) 或管道 |
git branch --contains $(git log --all -1 --format=%H -- file)
