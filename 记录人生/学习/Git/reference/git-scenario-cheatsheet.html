文件忽略与取消跟踪

echo "file" >> .gitignore
忽略从未跟踪过的文件（Untracked 文件专用）
git update-index --skip-worktree <file>
忽略已跟踪文件的本地修改（git status 不再显示）
git update-index --no-skip-worktree <file>
恢复：让 Git 重新关注这个文件的修改
git ls-files -v | grep '^S'
查看所有被 skip-worktree 标记的文件（S=skip, h=assume-unchanged）
git rm --cached <file>
永久停止跟踪文件（保留本地副本）。之后需加 .gitignore

决策：该用哪个？

git status 看到文件 → Untracked? → .gitignore
git status 看到文件 → modified? → skip-worktree（临时）或 rm --cached（永久）
